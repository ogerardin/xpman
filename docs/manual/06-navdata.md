# Nav data

![Nav data panel showing active data layers and validation messages](assets/screenshots/navdata.png)
*The Nav data panel.*

X-Plane can read navigation data from several layers. The Nav data panel shows each layer's status, AIRAC cycle, and any warnings or errors.

## Check active layers

Each card shows whether the layer is active, its position in the stack, and its cycle when available. A layer may be ignored because another layer overrides it; check the **overrides** or **ignored by** message to understand which data X-Plane will use.

Select the `?` help icon on a card for its folder, cycle, and other information. Expand the file list to see installed data files and their dates.

## Fix a warning or error

Read the message and use a fix button when one is offered. For example, a cycle mismatch between navigation files may offer to move an incompatible file to the Trash. Review the proposed action before applying it; the card refreshes afterward.

Choose **Reload** to rescan data or **Install** to install a navigation data archive. See [Installing add-ons](09-installing-addons.md).
