# Introduction

XPman helps you manage an [X-Plane](https://www.x-plane.com/) 11 or 12 installation. Use it to install and organize aircraft, scenery, navigation data, plugins, and tools, and to check for add-on and simulator updates.

## Install XPman

Download the latest package for your platform from [GitHub Releases](https://github.com/ogerardin/xpman/releases). Each package includes a Java runtime; you don't need to install Java separately.

| Platform | Package |
|:---------|:--------|
| macOS | `.dmg` or `.pkg` |
| Windows | `.exe` or `.msi` |
| Linux | `.deb` or `.rpm` |

The first time you open XPman, your operating system might ask you to approve it:

- **Windows:** In SmartScreen, select **More info**, then **Run anyway**.
- **macOS:** In **System Settings → Privacy & Security**, select **Open Anyway**.

For help with these prompts, see [Troubleshooting](12-troubleshooting.md).

## Next steps

Select your X-Plane folder to get started. See [Getting started](01-getting-started.md) for the first-launch guide.
