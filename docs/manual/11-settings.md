# Settings

Open Settings with **File → Settings** or the `Cmd/Ctrl + ,` shortcut.

## General

- **Confirm quit** — Show a confirmation before quitting XPman. Enabled by default.
- **Ignore beta updates** — Hide Beta offers for add-ons and X-Plane. Stable updates remain available. The setting takes effect when you choose **OK**.

## Tools

The **Tools** section opens the Tools manager. See [Tools](08-tools.md).

## Saved preferences

XPman saves preferences automatically in `~/.xpman`, including your selected X-Plane folder, recent folders, theme, window size and position, and scenery class rules. The Settings dialog also remembers its last selected section and position.
