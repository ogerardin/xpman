# Logging Improvements Implementation Plan

> **For agentic workers:** Implement the approved plan inline, verifying each task before proceeding.

**Goal:** Add bounded file logging, temporary debug logging, and ZIP log export to XPman.

**Architecture:** Platform implementations compute log locations. A Logback property definer resolves and creates the chosen directory during configuration loading; a small utility also zips the directory for export. The main-window Help menu exposes the runtime debug toggle and ZIP save dialog.

**Tech Stack:** Java 25, Logback 1.6.3, JavaFX, JUnit 5, `java.util.zip`.
